Reporting a Vulnerability

We take the security of this extension seriously. If you discover a security vulnerability within this project, please report it immediately.

How to report

Please do not open a public issue. Instead, report vulnerabilities by:

Sending an email to your contact email address (the one verified in your Chrome Developer Account).

Clearly describing the vulnerability, the steps to reproduce it, and the potential impact.

Response Process

You will receive an acknowledgment of your report within 48 hours.

We will provide an estimated timeline for a fix.

Once the vulnerability is resolved, a new version will be pushed to the Chrome Web Store and the GitHub repository.

Our Security Commitments

Local Storage: All sensitive data, such as your Google AI API Key, is stored strictly in your browser's local storage (chrome.storage.local). It is never synced to external servers by this extension.

Direct Communication: The extension communicates directly with Google's Gemini API endpoints via HTTPS. No middle-man servers are used.

No Data Harvesting: We do not collect or track the text you select or the responses generated by the AI.
