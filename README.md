✨ Gemini Proofreader With API usage of Gemini (Chrome Extension)

An extension for Google Chrome made from Gemini to Gemini, bringing the power of Google Gemini AI directly to your browser. Select any text, right-click, and let the AI correct it, change its tone, or translate it.

🚀 Features

🔍 Proofread & Fix: Corrects spelling and grammar mistakes, explaining exactly what was changed.

👔 Formal Tone: Rewrites your text to sound more formal (ideal for work emails).

👋 Casual Tone: Converts your text to a more relaxed, everyday tone.

🌍 Translation: Instantly translates the selected text to English.

⚡ Quick Replace: With one click (the "Replace" button), the corrected text is automatically inserted into the field you were typing in!

⚙️ Installation (Developer Mode)

Download or clone this folder to your computer.

Open Google Chrome and go to chrome://extensions/.

Enable "Developer mode" in the top right corner.

Click "Load unpacked" and select the folder.

🔑 How to get an API Key

For the extension to work, you need a (free) API Key from Google:

Visit Google AI Studio.

Sign in with your Google account.

Click "Create API Key".

Copy the key, click the extension icon in Chrome, and paste it into the options page.

⌨️ Keyboard Shortcuts

Default: Alt + Shift + G (Mac: Cmd + Shift + G).

You can configure the action the shortcut will perform from the extension options (e.g., always Proofread, or prompt you with a popup menu every time).
